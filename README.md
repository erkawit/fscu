# ระบบแบบสอบถามความพึงพอใจในการให้บริการ ศาลจังหวัดอุดรธานี

Google Apps Script Web App เก็บข้อมูลใน Google Sheet
https://docs.google.com/spreadsheets/d/1eR-fAiuNPTAq0veV6aWB9yBQyYnXAGYXsWYzq33YvJs

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | ฝั่งเซิร์ฟเวอร์: รับแบบสอบถาม, ล็อกอิน, สิทธิ์, จัดการผู้ใช้, อ่านข้อมูล |
| `Index.html` | หน้าแบบสอบถามสำหรับประชาชน |
| `Admin.html` | ระบบหลังบ้าน (แดชบอร์ด, ตาราง DataTables, รายงาน, PDF, QR, ผู้ใช้) |
| `appsscript.json` | ตั้งค่าเขตเวลา Asia/Bangkok และสิทธิ์ Web App |

## ขั้นตอนติดตั้ง (ประมาณ 5 นาที)

1. เปิด Google Sheet ข้างต้น → เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดเดิมใน `Code.gs` แล้ววางเนื้อหาไฟล์ `Code.gs` ทั้งหมด
3. กด **+ → HTML** สร้างไฟล์ชื่อ `Index` แล้ววางเนื้อหา `Index.html` ทำซ้ำสำหรับ `Admin`
   (ชื่อไฟล์ต้องเป็น `Index` และ `Admin` ตัวพิมพ์ใหญ่-เล็กตรงกัน)
4. ไปที่ **การตั้งค่าโปรเจกต์ (⚙)** → ติ๊ก "แสดงไฟล์ Manifest appsscript.json" → กลับไปที่ตัวแก้ไข เปิด `appsscript.json` แล้ววางเนื้อหาไฟล์นี้
5. เลือกฟังก์ชัน **`setup`** บนแถบเครื่องมือ → กด **เรียกใช้ (Run)** → อนุญาตสิทธิ์ (Review permissions → เลือกบัญชี → Advanced → Go to project → Allow)
   ระบบจะสร้างชีต `Responses`, `Users`, `Logs` และผู้ใช้เริ่มต้นให้
6. กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)** → ประเภท **เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**
   → กด Deploy แล้วคัดลอก URL ที่ลงท้ายด้วย `/exec`

## ลิงก์ใช้งาน

- หน้าแบบสอบถาม: `https://script.google.com/macros/s/.../exec`
- ระบบหลังบ้าน: `https://script.google.com/macros/s/.../exec?page=admin`
- แบบสอบถามที่เลือกส่วนงานไว้ให้: `...exec?unit=r05` (สร้าง QR ได้จากเมนู "QR Code แบบสอบถาม")

**บัญชีเริ่มต้น:** `admin` / `Admin@1234` — ระบบจะเตือนให้เปลี่ยนรหัสผ่านทันทีที่เข้าครั้งแรก

## สิทธิ์ผู้ใช้งาน

| สิทธิ์ | แดชบอร์ด / ความคิดเห็น / รายงาน / PDF / QR | จัดการบัญชีผู้ใช้ | ลบรายการแบบสอบถาม |
|---|---|---|---|
| แอดมิน | ✓ | ✓ | ✓ |
| หัวหน้าศาลฯ/ผู้อำนวยการฯ | ✓ | – | – |
| เจ้าหน้าที่ | ✓ | – | – |

## ความสามารถของระบบ

- แบบสอบถาม 5 ข้อตามที่กำหนด, ส่วนงานที่มีงานย่อยจะให้เลือกงานย่อย, "อื่นๆ" มีช่องระบุ, ให้ดาว 1–5 พร้อมคำอธิบายใต้ดาว
- วันที่-เวลาบันทึกจากเซิร์ฟเวอร์ (Asia/Bangkok) เท่านั้น ผู้กรอกแก้ไขไม่ได้
- หลังส่งแบบสอบถาม หน้าจอกลับสู่ฟอร์มใหม่อัตโนมัติใน 20 วินาที (เหมาะกับแท็บเล็ตตั้งที่จุดบริการ)
- ระบบหลังบ้าน: แดชบอร์ดพร้อมกราฟ, ตาราง DataTables + ตัวกรองวันที่/ส่วนงาน/คะแนน, ปุ่ม "รายละเอียด" (SweetAlert), ส่งออก CSV
- **PDF สร้างเป็นไฟล์จริง กระดาษ A4 แนวนอน** (จัดหน้า, หัวตารางซ้ำทุกหน้า, เลขหน้า) — ไม่ใช้ PDF Printer ของเบราว์เซอร์
  - รายการความคิดเห็น (ตามตัวกรองที่แสดงอยู่), รายการเดี่ยว, รายงานรายวัน/เดือน/ปี/ปีงบประมาณ/ช่วงกำหนดเอง
- รายงานแสดง: จำนวน, ค่าเฉลี่ย, ร้อยละ, ระดับ, จำแนกตามระดับคะแนน/เพศ/อายุ/ส่วนงาน (+งานย่อย)/ช่วงเวลา, ความคิดเห็น, ช่องลงนาม
- เกณฑ์แปลผล: 4.51–5.00 ดีเยี่ยม · 3.51–4.50 ดี · 2.51–3.50 ปานกลาง · 1.51–2.50 พอใช้ · 1.00–1.50 ปรับปรุง · ร้อยละ = ค่าเฉลี่ย × 20
- ความปลอดภัย: รหัสผ่านเก็บแบบ hash + salt, ล็อกชั่วคราวเมื่อกรอกผิด 5 ครั้ง, session หมดอายุ 6 ชม., กันสูตรใน Sheet, กันบอท, บันทึกประวัติการใช้งานในชีต `Logs`

## การแก้ไขภายหลัง

- เปลี่ยนชื่อส่วนงาน/งานย่อย/ช่วงอายุ: แก้ที่ `SERVICES` และ `AGE_RANGES` ใน `Code.gs`
- ทุกครั้งที่แก้โค้ด: **Deploy → จัดการการทำให้ใช้งานได้ → ✏ แก้ไข → เวอร์ชัน: เวอร์ชันใหม่ → Deploy** (URL เดิมใช้ต่อได้)
- หากลืมรหัสแอดมินทั้งหมด: ลบแถวผู้ใช้ใน `Users` ให้เหลือแค่หัวตาราง แล้วเรียก `setup` อีกครั้ง
